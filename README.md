# Fa.Bucha — Final Website Starter

Website landing page responsif untuk brand kombucha Fa.Bucha.

## Isi folder
- `index.html` — halaman utama, produk, cerita brand, dan materi pembelajaran.
- `style.css` — layout responsif, warna brand, animasi gradient, ilustrasi, dan modal.
- `script.js` — menu mobile, pilihan order WhatsApp/Instagram, dan materi belajar interaktif.
- `images/original.png` — foto botol Original dengan latar transparan.
- `images/telang.png` — foto botol Telang dengan latar transparan.
- `images/rosella.png` — foto botol Rosella dengan latar transparan.

Versi JPG sumber juga disertakan di folder `images/` sebagai cadangan.

## Materi pembelajaran
Bagian “Belajar bareng Fa.Bucha” memiliki empat materi yang dapat dibuka terpisah:
1. Apa itu kombucha?
2. Kenalan dengan SCOBY
3. Proses fermentasi
4. Merawat dan menyimpan kombucha

Materi ditulis sebagai edukasi umum dan menghindari klaim bahwa kombucha mengobati atau mencegah penyakit.

## Deploy lewat HP dengan GitHub + Vercel
1. Ekstrak ZIP ini di HP.
2. Upload semua isi folder ke root repository GitHub, termasuk folder `images/`.
3. Pastikan file lama `index.html`, `style.css`, dan `script.js` diganti.
4. Commit changes.
5. Jika repository sudah terhubung ke Vercel, deployment biasanya berjalan otomatis.

Website statis ini tidak membutuhkan build command.

## Catatan
Foto botol diambil dari referensi visual yang diberikan dan latarnya dihapus secara otomatis. Periksa hasil cutout pada beberapa perangkat sebelum publikasi. Tambahkan harga, ukuran, petunjuk penyimpanan, serta informasi produk yang telah dikonfirmasi sebelum website diluncurkan.
